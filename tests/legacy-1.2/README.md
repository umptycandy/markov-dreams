# Mutable Dreams 1.2 UI scripts (not run)

These host-simulator scripts drive the 1.2 pages (Sound, Filter, Rhythm, Grain, Mixer, Banks, MIDI, ...).
Markov Dreams hides those pages from the panel; their code is still in `app/app.c`. The scripts are kept
for reference and for anyone who brings a page back. The Markov Dreams workflow is checked by
`tests/markov_ui.txt`.
